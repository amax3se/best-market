# The Best Market
Here is my online shop. You can buy some things there, create acount, log in and etc. *It's just an educational project*

## Technologies
- Java
- NetBeans IDE

## Working files
The program is using .txt files to save data (I know that this is stupid, but I have write that app in my 13-14, I was not very smart too):
- `account.txt` — your account name, mail and password
- `product.txt` — current products
- `amount.txt` — all your products with the final price
- `product_table.txt` — all your products

## Installation
**1. With NetBeans:** \
Open project and rush on "play" button
